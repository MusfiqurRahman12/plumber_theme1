# PlumberX - Professional Plumbing & Repair Services Website

A modern, responsive, 13-page website built for **PlumberX** (Plumbing & Handyman Services), styled and crafted according to full mockup specifications with high-resolution photography, transparent cutouts, and interactive JavaScript components.

**Site Development:** [Ztech Communication](https://www.ztechbd.com)

---

## 🌟 Pages Overview (13 Complete Pages)

1. **Home (`index.html`)** - Hero banner with quick quote estimator, service tabs, projects gallery, pricing coupons, client testimonials, and trust badges.
2. **About Us (`about.html`)** - Company story, 25-year milestone counter, mission statements, leadership team cards, and satisfaction guarantees.
3. **Services 1 (`services-1.html`)** - Detailed service overview with interactive room tabs (Kitchen, Bathroom, Commercial) and feature highlights.
4. **Services 2 (`services-2.html`)** - 8-card grid covering emergency leaks, sewer cleaning, drain clearing, gas line maintenance, remodeling, and HVAC heating.
5. **Services 3 (`services-3.html`)** - Modern list layout with call-to-actions, water splash accents, and emergency dispatch widgets.
6. **Plumbing Repairs (`service-repair.html`)** - Deep dive into plumbing repair services with sidebar navigation, repair benefits, and downloadable brochures.
7. **Projects Gallery (`projects.html`)** - Categorized project portfolio with dynamic filtering (All, Bathroom, Commercial, Kitchen, Plumbing) and modal lightbox preview.
8. **Case Study (`case-study.html`)** - Complete project case study with problem analysis, solutions, gallery, and client results.
9. **Shop Store (`shop.html`)** - Plumbing tools, hardware, and safety equipment with a live sliding cart drawer, quantity controls, and cart badge counter.
10. **Pricing Plans (`price.html`)** - Transparent service pricing cards with category filters, feature breakdowns, and booking buttons.
11. **Blog Default (`blog.html`)** - Plumbing tips, maintenance articles, category widgets, recent news sidebar, search bar, and tags.
12. **Single Blog Post (`blog-single.html`)** - Article view with formatted typography, blockquotes, author bio box, comment discussion form, and social share links.
13. **Contact Us (`contact.html`)** - Interactive contact form, 24/7 emergency hotline cards, office locations, and NYC service coverage map.

---

## 🚀 Key Features

- **Full Responsive Design:** Optimized for mobile, tablet, laptop, and ultra-wide desktop viewports.
- **High-Resolution Photography:** Over 80 high-definition assets, including transparent character and tool cutouts (`home_hero_plumber.png`, `shop_hero_toilet_clean.png`, `emergency_wrench.png`, `footer_plumber.png`, etc.).
- **Interactive Components (`js/main.js`):**
  - Instant Lightbox modal for project galleries.
  - Interactive Quote request forms (Residential / Commercial).
  - Sliding Cart Drawer with add-to-cart, remove, and quantity updates.
  - Dynamic category filters on Projects and Pricing pages.
  - FAQ Accordions with smooth toggle transitions.
  - Mobile hamburger navigation menu.
- **Design System (`css/style.css`):**
  - Deep Navy (`#062539`), Tech Blue (`#093751`), Accent Red (`#eb3b3b`), Accent Cyan (`#38bdf8`), and Gold accents.
  - Typography using modern Google Fonts (*Poppins* & *Inter*).
  - Clean CSS gradients and micro-animations.

## 💻 Local Preview

Run any local HTTP server in the project directory:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.
